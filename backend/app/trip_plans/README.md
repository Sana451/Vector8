# trip_plans

Сохранённый маршрут: заморозка результата оптимизатора + «живой» маршрут от
HERE, который реально заезжает в выбранные заправки (`via`).

## Жизненный цикл

`draft` → `refined` / `refine_failed` → `assigned` → `in_progress` → `completed`
(или `cancelled`). Назад в `draft` вернуться нельзя; снятие водителя откатывает
статус к `refined` / `refine_failed` / `draft`.

## Роли и доступ

| Роль | Видит | Может |
|------|-------|-------|
| admin / superuser | все поездки | всё |
| dispatcher | свои поездки | создавать, уточнять, назначать, менять статус (`assigned`, `in_progress`, `completed`, `cancelled`), удалять, публиковать ссылку |
| driver | только назначенные ему | статусы `in_progress`, `completed`, экспорт |

Правила — в `service.py` (`can_access`, `can_manage`).

## Эндпоинты (`/api/v1/trip-plans`)

| Метод | Путь | Назначение |
|-------|------|-----------|
| POST | `/` | создать из результата оптимизатора и уточнить маршрут |
| GET | `/`, `/my` | список диспетчера / водителя |
| GET | `/{id}` | детали: стопы, геометрии, дельта |
| POST | `/{id}/refine` | пересчитать маршрут через HERE |
| POST | `/{id}/assign` | назначить / снять водителя |
| PATCH | `/{id}/status` | сменить статус |
| GET | `/{id}/export.{gpx,kml,csv}` | экспорт для навигатора |
| POST | `/{id}/share` | выдать (`enabled=true`) или отозвать ссылку |
| GET | `/shared/{token}` | публичный просмотр без авторизации |
| DELETE | `/{id}` | удалить |

Статические `/my` и `/shared/{token}` должны быть зарегистрированы раньше
`/{id}`.

## Экспорт

GPX / KML / CSV строятся в `export.py`. Точки старта и финиша не хранятся в
`stops_snapshot`: `TripPlanService._with_endpoints` выводит их из первой и
последней точки геометрии маршрута (`kind=start` / `kind=destination`) и
добавляет во все ответы и экспорты. Трек прореживается до 2000 точек
(`thin_track`). На фронтенде `lib/navigatorLinks.ts` дополнительно строит
ссылки Google Maps (разбивка на участки по 8 точек) и HERE WeGo.

## Публичная ссылка

- Токен — `secrets.token_urlsafe(32)`, хранится в `trip_plans.share_token`.
- Повторная выдача возвращает тот же токен; отзыв обнуляет его, старая ссылка
  навсегда перестаёт работать (404).
- Публичный ответ не содержит id владельца, водителя и машины.
- API деталей отдаёт только флаг `is_shared`, сам токен не раскрывается.
- Страница: `frontend/src/routes/trip/$token.tsx` (вне `_layout`).

## Ограничения HERE

Число `via`-точек ограничено провайдером; при превышении уточнение
завершается `refine_failed` с текстом ошибки в `refine_error`.
